## Features

- **Activity goals**: Set a daily goal per activity type in the dashboard settings; the dashboard and popup show today's progress per activity, and goals sync with your account.
- **Attention modes**: The popup now offers Auto, Active and Passive. Auto detects attention per video as before; Active or Passive stays in effect for every following video until you change it.
- **YouTube music opt-out**: Videos YouTube classifies as music are skipped by default and shown as skipped in the popup. A new setting turns music tracking back on.

## Fixes

- **Day start hour**: A custom day start set on jp343.com is now picked up by the extension instead of being pushed back to midnight by a device that never learned it.
- **Twitch thumbnails**: Placeholder images of not yet processed VODs are no longer saved as session thumbnails.

## Improvements

- **Daily goal range**: The daily goal can now be set up to 24 hours.
- **Popup layout**: Stop and Pause take less space, and Pause only shows for manual page tracking where it has an effect.
