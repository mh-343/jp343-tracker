## Fixes

- **Japanese YouTube interface**: With YouTube set to Japanese, English videos could be tracked as Japanese immersion, for example collaborations, whose channel line YouTube writes in Japanese, or videos whose title YouTube translated into Japanese. Detection now goes by the original title and the uploading channel's name, so a video counts the same as it would on an English interface.
- **GameSentenceMiner in Firefox**: In Firefox, GameSentenceMiner sync and the history import kept showing "Start GameSentenceMiner on this computer" even while it was running. It now connects after you allow local access once; if you had already switched the sync on, click "Allow access" in the dashboard settings.
- **GameSentenceMiner port**: GameSentenceMiner installations updated from an older version can run on port 55000 instead of 7275, and the extension did not find them. It now tries both ports and remembers the one that answers; if you switched the sync on before this update and GameSentenceMiner runs on port 55000, click "Allow access" once.
